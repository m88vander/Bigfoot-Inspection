# 🦶 Bigfoot Daily Inspection Checklist

Offline-capable daily inspection checklist app with auto-email PDF reports.

## Features

✅ **Offline-Capable** - Works completely without internet  
✅ **Mobile-Friendly** - Works on Android and Apple phones  
✅ **QR Code Sharing** - Easy link sharing with team  
✅ **PDF Reports** - Professional inspection reports  
✅ **Auto-Email** - Reports sent to oslumaintmgrs@onni.com  
✅ **History Tracking** - View all past inspections  

## How to Use

1. **Open the app**: https://m88vander.github.io/Bigfoot-Inspection/
2. **Fill in your details**: Date, shift, technician name
3. **Complete the checklist**: Mark each item as Pass or Fail
4. **Submit**: Click "Submit & Send Report"
5. **Share**: Use the QR code in the "Share Link" tab

## Inspection Items

- Body & Structure
- Lights & Alarms
- Controls & Pedals
- Seat Belts
- Locking Devices
- Interlock Switches
- Battery & Electrical
- Weekly Inspection (Qualified Technician)

## Report Details

Each report includes:
- Date and shift information
- Technician name
- All 28 inspection items with Pass/Fail status
- Additional notes
- Timestamp of submission

Reports are automatically emailed to: **oslumaintmgrs@onni.com**
